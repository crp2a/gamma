# Clermont Reference Data

Clermont Reference Data

## Usage

``` r
data("clermont")
```

## Format

A [`data.frame`](https://rdrr.io/r/base/data.frame.html) with tabulated
data and conversion factor reference.

## Source

Guérin, G., Mercier, N. & Adamiec, G. (2011). Dose-Rate Conversion
Factors: Update. *Ancient TL*, 29(1), p. 5-8.
[doi:10.26034/la.atl.2011.443](https://doi.org/10.26034/la.atl.2011.443)

Miallier, D., Guérin, G., Mercier, N., Pilleyre, T. & Sanzelle, S.
(2009). The Clermont Radiometric Reference Rocks: A Convenient Tool for
Dosimetric Purposes. *Ancient TL*, 27(2), p. 37-44.
[doi:10.26034/la.atl.2009.428](https://doi.org/10.26034/la.atl.2009.428)
