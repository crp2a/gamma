# Heidelberg Reference Data 2024

Reference data for the calibration sites near Heidelberg as detailed in
Kreutzer at al. (2025)

## Usage

``` r
data("heidelberg_2024")
```

## Format

A [`data.frame`](https://rdrr.io/r/base/data.frame.html) with tabulated
data and conversion factor reference.
