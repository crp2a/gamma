# Lanthanum Decay Data

An internal dataset containing the decay data for the Lanthanum
isotopes.

## Format

A [`data.frame`](https://rdrr.io/r/base/data.frame.html) with the
following columns (absolute errors):

- decay_chain:

- isotope:

- occurrence:

- occurrence_error:

- post_radon:

- half_life:

- half_life_error:

- energy:

  Energy in keV.

- energy_error:

- gamma_intensity:

- gamma_intensity_error:

## Source

Nuclides And Isotopes : Chart of the Nuclides.
