# Clermont Reference Data 2024

An updated version for the `clermont` dataset with additional columns
for the applied dose rate conversion factors and their reference. The
dataset also contains gamma dose rate values and uncertainties for
different published conversion factors. Please note that the values for
the conversion factors applied in the original `clermont` dataset differ
slightly due to rounding errors.

## Usage

``` r
data("clermont_2024")
```

## Format

A [`data.frame`](https://rdrr.io/r/base/data.frame.html) with tabulated
data and conversion factor reference.
