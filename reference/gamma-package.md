# gamma: Dose Rate Estimation from in-Situ Gamma-Ray Spectrometry Measurements

Process in-situ Gamma-Ray Spectrometry for Luminescence Dating. This
package allows to import, inspect and correct the energy shifts of
gamma-ray spectra. It provides methods for estimating the gamma dose
rate by the use of a calibration curve as described in Mercier and
Falguères (2007). The package only supports Canberra CNF and TKA and
Kromek SPE files.
